# 🍎 FreshLens CNN - Fruits & Vegetables Classification

An end-to-end Computer Vision project using Convolutional Neural Networks (CNN) in TensorFlow/Keras to classify images of fruits and vegetables into their respective categories.

---

## 📌 Project Overview

This project builds a deep learning image classification model capable of distinguishing between various fruit and vegetable classes. The pipeline covers dataset loading, image preprocessing, batching, CNN architecture design, evaluation, and inference.

---

## 🛠️ Tech Stack & Tools

- **Programming Language:** Python 3.x
- **Deep Learning Framework:** TensorFlow / Keras
- **Data Manipulation & Processing:** NumPy, Pandas, OpenCV
- **Visualization:** Matplotlib, Seaborn
- **Deployment / Demo:** Streamlit (Optional)
